# Zebra Studio

Composition et impression Bluetooth (BLE) pour imprimante Zebra ZQ310, à ouvrir dans Bluefy.

- `index.html` + `app.js` : l'appli
- `test-ble.html` : page de test de connexion
- `lib/` : pdf.js 3.11 (Apache 2.0), qrcode-generator 1.4.4 (MIT), JsBarcode Code 128 (MIT)
- `fonts/` : 16 polices Fontsource (OFL / Apache) — voir fonts.css
